# Competitive Research Workflow

Performs exhaustive competitive intelligence gathering for a given product or product category.

## Step 1 — Define the Search Space
1. Identify the product category (e.g., "AI geopolitical simulation", "alternate history generation")
2. Identify the target personas from the PDR
3. List 3-5 search queries covering: direct competitors, adjacent tools, open-source alternatives

## Step 2 — Direct Competitor Deep Dive
// turbo-all
4. Search the web for each direct competitor mentioned in the PDR. For each one, gather:
   - Core features and capabilities
   - Pricing and business model
   - Target audience
   - Technical architecture (if public)
   - User reviews, complaints, and praise
   - Funding/team size if available
5. Search for competitors NOT mentioned in the PDR using category-level queries
6. Search for academic or research tools in the same space
7. Search for open-source projects that solve similar problems

## Step 3 — Persona-Based Competitor Mapping
8. For each target persona, identify which existing tools they currently use
9. Search for Reddit, Twitter/X, and forum discussions where the target audience discusses their unmet needs
10. Identify the "current alternative" for each persona (the tool they use today, even if it's manual)

## Step 4 — Pricing Intelligence
11. Search for SaaS pricing benchmarks in the AI tools category
12. Compare the PDR's pricing against competitor pricing (if available)
13. Search for freemium conversion benchmarks in similar categories

## Step 5 — Moat Analysis
14. For each competitor, assess:
    - Network effects (does the product get better with more users?)
    - Data moats (does accumulated data create switching costs?)
    - Brand/design moats (is the product visually distinctive?)
    - Technical moats (is the architecture hard to replicate?)
15. Assess the PDR product's moat potential against each dimension

## Step 6 — Competitive Positioning Matrix
16. Create a feature comparison table: PDR product vs. top 5 competitors
17. Identify the PDR product's unique positioning gap — the space no competitor occupies
18. Document recommended positioning adjustments based on findings
